# v2.0.0

发布日期：2026-10-24

这是个**破坏性变更**版本：包名变了，旧版不能覆盖安装。

## 为什么

这个工具是通用的，但之前的代码里带着具体型号的痕迹：

- 包名 `com.mibox3.memclean` 直接写死了小米盒子3 的型号代码
- 白名单初始化硬编码了 `com.oversea.aslauncher`（Emotn 桌面）和
  `com.android.inputmethod.pinyin`（AOSP 拼音输入法）

换一台盒子、换一个桌面，就会保护错对象——桌面被清掉，或者输入法被清掉导致无法输入。

## 改了什么

### 包名

`com.mibox3.memclean` → **`io.github.wavebird.memclean`**

### 白名单改为运行时探测

| 组件 | 获取方式 |
| --- | --- |
| 桌面 | `queryIntentActivities(ACTION_MAIN + CATEGORY_HOME)`，装了几个保护几个 |
| 输入法 | `InputMethodManager.getInputMethodList()`，`Settings.Secure.DEFAULT_INPUT_METHOD` 兜底 |
| 系统界面 | `com.android.systemui`（所有 Android 都有） |

只有四个 AOSP 标准包名还是写死的，它们在任何 Android 上都一样：

```
com.android.systemui
com.android.bluetooth
com.android.phone
com.android.providers.telephony
```

`Prefs.isLocked(pkg)` 相应改为 `Prefs.isLocked(ctx, pkg)`，因为锁定集合现在要查系统。

## 升级说明

包名变了，Android 会当成两个不同的应用，**不能覆盖安装**：

```bash
adb uninstall com.mibox3.memclean
adb install -r memclean-2.0.0.apk
adb shell appops set io.github.wavebird.memclean GET_USAGE_STATS allow
adb shell am startservice -n io.github.wavebird.memclean/.MemCleanService
```

卸载会清掉旧版的白名单和清理记录。新版首次启动会按当前设备重新探测，
自动把本机的桌面和输入法加进保护名单，一般不需要手动重配。

## 已知问题

- Android 8.0+ 未适配（需要前台服务）
- 清理是无差别的，后台放歌/下载会被中断，需加白名单
- 清理记录最多 200 条，不支持导出
